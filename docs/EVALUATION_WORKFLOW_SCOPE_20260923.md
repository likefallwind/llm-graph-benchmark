# 已确定评估指标与统一工作流范围（2026-09-23）

状态：指标展示范围已确定，现有功能与差距已核实。本文是整合规范，不代表已经实现一键完整评测。

## 最终指标
- 完整断言正确、错误、不确定；关系表达L1/L2/L3；具体且正确覆盖及L3内正确率。
- 实体所指正确、实体引用支持；类型标签兼容正确率、正确类型粒度；描述上下文支持、整段支持。
- 别名同一性、实体拆分。
- Book QA支持、完整事实探针覆盖。
- 图规模、引用存在、连通性、原生字段覆盖、别名条目数。
- 构图输入/输出/总Token，以million为单位。
历史断言引用支持率不再展示或作为新运行的独立必评项，原始记录留档。类型正确性与粒度分开，不形成任意加权总分。

## 当前已有能力
公共包src/llm_graph_benchmark提供submission/benchmark契约、校验、确定性抽样、身份任务、QA任务、检索、结构指标、聚合和报告；CLI有对应子命令，但没有覆盖最新指标的统一run命令或公共模型调度入口。
最新MiniMax调用、并发上限、后台执行、断点恢复、完整断言裁判、类型与描述逐项评分、粒度细分及整表汇总位于studies与冻结outputs中；多个脚本带有本次实验的路径、日期、样本复用及方法列表，不能直接称为任意新图谱通用流水线。
一个裁判任务可以派生多个统计量：类型判定同时给出正确性和粒度；完整断言及关系粒度结果结合生成具体且正确覆盖，无需为每行统计单独调用模型。

## 目标工作流
统一配置 → 载入/适配新图谱与原文 → 校验端点、字段和来源映射 → 固定随机抽样与检索 → 自动结构统计 → 全局受限并发语义评测 → 技术失败恢复 → 汇总质量、粒度、覆盖、规模、成本 → 输出对照表与逐条明细。
默认沿用当前规模：实体100、断言200、别名30、实体拆分30；QA和探针数量由benchmark提供，当前D2L为24/48。模型MiniMax-M3，全局并发不超过6，包括重试。
同一本书的新图谱可复用已冻结benchmark、QA、探针与检索配置；新书需准备对应原文和来源侧QA/探针。更换本体字段需适配到中立submission，不以自然语言生成不存在的原生字段。
成本需由构图日志或runtime元数据提供；仅有最终图谱不能恢复过去的Token用量。

## 必须统一的部分
- 指标注册表及版本；抽样、字段缺失、证据范围和分母。
- 类型标签与判定明确绑定标签文本及ID，不能只靠位置索引；不能把实体是否值得建模混入类型判断。
- 描述判定保留原文片段约束；结构检查不能宣称语义判断绝对可靠。
- 统一一个全局6请求池，成功结果缓存不重跑，只对技术失败有限重试；保存原请求与原响应。
- 冻结来源哈希、图谱版本、提示版本、检索参数、模型与抽样种子；没有字段记N/A，不把技术失败当错误。
- 旧QA/实体拆分协议的证据展示限制在报告中标明；任何修正另升版本，不能静默与历史分数混比。
- 同一来源上的新旧图谱比较可复用源侧基准，但实体ID变化时不能声称随机抽样已成为同实体配对实验。

验收：合成小样例可完成全流程；默认只准备任务/估算调用数，明确执行才调用API；运行中可查询状态、恢复和导出；全部已选指标都有来源、分母、缺失状态及可复核明细。
