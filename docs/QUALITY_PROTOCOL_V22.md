# 来源支持的单条断言质量 v2.2

本协议沿用既有 Benchmark 的材料、系统输出与抽样框架。主要测量“输出实际声称的命题是否得到来源支持”，不要求单条断言覆盖整段材料，也不保证来源自身科学正确。

## 语义判定

- 独立事实 A、B 可以分开抽取；少抽 A 不使 B 错误。
- 改变本条命题真值的条件、数量、模态、否定、时间和实验语境必须保留。
- 正确描述不能修复错误关系、方向或实体角色。同条 text/scope 可以补充限定，不能替换错误端点或谓词。
- 不因长节点、事件节点、不同字段布局、明确等价的术语改写或不影响意思的重复直接扣分。
- 来源可读但未支持输出的具体命题（包括无根据消歧）为 fail；这不是断言在现实中必然为假。
- 来源缺失、关键内容不可读取、或相互冲突且无法确定有效版本时 uncertain；API/解析异常独立记 error。

## 输出和程序约束

实际指令冻结于 `RULES['assertion_quality_v2_2']`。公开任务仅含规则、内容和来源，不含系统、旧标签、复核标签或预期答案。

```json
{
  "evaluated_triple": {"subject": "原值", "predicate": "原值", "object": "原值"},
  "edge_label": "pass|fail|uncertain",
  "description_label": "pass|fail|uncertain",
  "condition_label": "pass|fail|uncertain",
  "label": "pass|fail|uncertain",
  "reason": "按各项说明输出字段与来源依据"
}
```

程序必须核对回填主谓宾与输入逐字相同。分项只接受三个语义标签。任一 fail → 联合 fail；无 fail 但有 uncertain → 联合 uncertain；三个 pass → 联合 pass。返回联合标签与规则不符属于无效响应，不算语义判定。
保留每次原始响应及失败原因。只对无效响应或调用失败重试，不挑选更有利的有效标签。
程序检查解决的是输入读取一致性和分项汇总，不能证明各个语义判断本身正确。

## 报告口径

主表报告联合 pass/all、pass/decided、fail、uncertain 与覆盖率；三个分项另表，不相乘。
无证据共现边记 uncertain；有证据的共现可以在其有限命题上正确，但不能据此声称已抽出有价值的语义知识。GraphRAG Fast 单列为共现参照。

原 48 条多候选事实恢复是辅助检索/覆盖诊断，保留旧任务和分数，不与本次不同抽样总体的单条精度拼 F1。
同书、各方法各自输出样本的二项区间不是跨语料置信结论；跨方法不能用不对应的断言做配对检验。
当前 AutoSchemaKG/KGGen/GraphRAG 基线的阶段与配置局限仍然存在。完整性、可靠性与方法领先是三种不同结论。
