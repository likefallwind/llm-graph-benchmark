# 单条断言质量协议 v2

这是现有 Benchmark 的评分协议修订，不是新的领域标准。v1 的规则、数据和标签保持原样。
核心研究问题：输出断言是否能在显式限定下被直接信赖，同时具有有价值的知识覆盖。

## 评价单位与判定

评价同条 subject、predicate、object、text、scope、polarity 实际声称的命题。原文作为核对
证据，不是供裁判替输出补全或纠错的材料。不能读取其他候选修复本条断言。

- 来源独立支持 A 和 B，单独抽出 B 可以正确；遗漏 A 属于覆盖问题。
- 省略改变本条命题真值的条件、否定、模态、数量或实验语境属于准确性问题。
- 局部收益不等于整体收益；单独抽局部收益可以正确，但不得添加整体改善或充分性的含义。
- text/scope 可以保存本条限定；不得用正确描述掩盖错误谓词、方向、端点或内部矛盾。
- 明确等价的符号替换、轻微重复不自动构成事实错误。实体/事件节点和字段布局均不决定分数。
- 长句节点不自动扣分或得分，必须评价它实际连接的关系是否被支持。

主指标为 `assertion_quality_v2` 的联合通过率。错误原因分为 unsupported、entity_role、
relation_direction、truth_condition、internal_conflict；原因标签供审计，不能未经复核从
自由文本直接生成可靠的错误类型频率。pass、fail、uncertain 分开报告，API/解析错误另列。
报告 pass/all、pass/decided、判定覆盖率和未完成状态；不把不确定项或 API 错误称为事实错误。
现有 Wilson 区间仅描述明确判定样本，不能覆盖裁判误差或同书相关性，不用于宣告全领域 SOTA。

## 覆盖与成本

`fact_recovery_strict_v1`、`fact_recovery_core_v1` 保持任务和规则不变，角色降为辅助的
多候选信息恢复诊断。它们受候选检索、承载文本量和裁判语义匹配影响，不等于结构正确率，
也不是全面的原子事实召回。不得与单条断言精度直接拼接 F1。
后续需从来源独立标注原子事实，比较相近覆盖下精度、相同精度门槛下的去重有效事实量，
并报告抽取和后验校验成本。没有可比较的筛选分数时不伪造精度—覆盖曲线。

## 固定数据和版本隔离

`quality-tasks --version v2` 仅将旧 assertion_grounding 转为 assertion_quality_v2；
fact_recovery 仍生成字节等价的 v1 恢复任务。默认 v1 保持旧调用兼容。
新 kind、rubric hash 参与任务 ID；任何规则变动必须新建任务，不能沿用旧标签。
D2L 准备脚本复用五系统各 200 条历史断言，不改变内容、来源证据或抽样总体。
AutoSchemaKG 仅语义抽取子集、KGGen 未执行 LLM 归一、GraphRAG 中文语料使用 Fast 英文配置
等既有局限继续标注，不因协议升级而成为完整强基线。

## 规则检查与独立复核

1. 冻结协议及 26 条合成规则检查（12 组正反例 + 2 条不确定例）。预期标签仅在私有 key。
   必须全部匹配且无缺失/API 错误，才算通过这组最小规则检查。这个门槛事先固定。
2. 合成样例由助手按规则编写，是开发测试，不是独立人工金标准、不是留出集，
   全部通过也不代表真实样本裁判准确。
3. 从五系统 x 历史标签各抽至多 8 条，作为开发复核集。私有 key 保存层大小、抽样概率和
   逆概率权重；公开任务不含系统、旧标签、预期答案。不得直接将分层样本命中率视作总体准确率。
4. 正式确认性比较之前，还需从未用于修改规则的自然样本构造留出复核集，按同一规则独立判定。
   错误接受、错误拒绝、不确定、分系统差异分别报告。独立模型一致不等于人工校准。
   修改规则后，已查看过的留出集转为开发材料，不能继续称为独立留出验证。
5. 规则检查不过时停止全量派发，保留原始响应和失败例；不能挑选成功重试覆盖有效但不合预期的标签。

## 方法贡献的必要对照（后续）

基线原始输出、基线 + 等预算统一校验、本方法完整流程、本方法关键环节消融。
检验优势能否由普通抽取加筛选解释；校验使用同样信息权限并计入成本，评测裁判与方法内校验
角色分开。机制解释需来自消融和实际错误审计，不能仅凭最终通过率推断。

## 本轮边界

本轮交付协议、版本隔离工具、冻结任务、合成规则检查及分层开发复核材料。
只有真实 API 产物能证明规则检查运行完成；软件测试通过不等于测量已校准。
独立留出复核完成前不自动启动确认性的 1000 条重评分，不把旧 88.5% 当作 v2 准确率。
