# D2L 关系表达粒度补评 v1

复用历史可靠性补评的 800 条断言，每方法 200 条，不重新抽样、不改写图谱或正确性标签。只按完整输出判粒度，不向裁判发送原文、系统名或旧分数。GraphRAG 原生描述正常计入。

L1：泛关联，无具体关系性质。L2：宽泛关系类别，具体作用或角色未明确。L3：明确具体可核验的关系。uncertain：无法解释或区分相邻层次。粒度与真假独立，具体但错误仍可为 L3；不按词表、句长或谓词数量评分。

MiniMax-M3 官方 API，全方法及重试共享 6 个 HTTP 槽。凭证只从继承环境 MINIMAX_API_KEY 获取。格式或调用失败最多三次尝试，有效标签不重试。保留全部原始响应与用量，无权威价格不估算费用。

先执行冻结的合成开发检查。检查只是规则理解诊断，不是独立校准；保留结果并继续用户授权的探索性评分，不按正式标签反复调规则。认证或额度终止错误停止派发。

报告 L1/L2/L3/uncertain/未判定计数与固定分母比例；各层报告正确/层内全部、正确/明确判定、正确性不确定与缺失及Wilson区间。不将粒度比例与总体正确率相乘，不生成加权总分。旧正确性标签来自有已知误判的探索性裁判，不能据此可靠排名。

沿用历史剩余可抽样总体。AutoSchemaKG 为排除事件参与边、自环和空字段的既定语义子集。没有进行跨书验证。

准备：evaluate.py prepare --source-run <旧目录> --run <新目录>。
后台：冻结目录的 background.py launch --run <新目录>。
完成需 .exit=0、.finished 以及 800 个有效粒度判定；技术完成不是独立效度验证。
