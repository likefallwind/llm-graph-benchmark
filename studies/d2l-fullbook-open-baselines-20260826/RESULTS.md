## 各列指标的含义

| 指标 | 测什么 | 口径与陷阱 |
|---|---|---|
| **grounding** | 来源证据是否支持该断言陈述的内容 | 只判内容真假，明确要求忽略三元组结构与限定条件 |
| **projection** | (主,谓,宾) 是否忠实投影原文关系：方向、谓词语义与强度、主宾粒度 | prompt 明写「**假设内容本身成立**」。因此对只有共现边的系统会虚高——GraphRAG 68.1% 不代表质量，代表这种关系形式没有投影错误可犯 |
| **scope** | scope 与 text 是否忠实保留原文限定（条件/范围/时间/对象/否定），不丢也不加 | 同样假设内容成立。加限定与丢限定都算 fail |
| **三轴全过** | 同一条断言三轴都 pass（uncertain 计为不过） | 最贴近「可直接下游消费」的读数，也是 F 表的乘数 |
| **uncertain** | 裁判无法就该轴作判断的比例 | 本身是信号。高 uncertain = 断言不构成可判定的命题（GraphRAG 18.8%） |
| **CaRB 召回** | 检索到的候选中，是否**存在一条或多条**共同覆盖了该源事实 | 多匹配、噪声不扣分。取代了 v2 的 fact_recovery |
| **fact_recovery (v2)** | 单条候选须独立承载全部内容，且不添加证据外内容 | **已作废**。图越大越容易在 top-10 混入无关断言而被判负，KGGen `exact` 因此被压到 6.3% |
| **book_qa** | 24 道全书 QA，答案能否由检索到的图内容支撑 | v2 口径，未重判；受同一「大图吃亏」偏差影响，量级可能被低估 |
| **entity_admission** | 该实体是否应当被收进图（是不是真概念，而非碎片） | v2，n≈28–29。±15pp，相邻两列差距不可据此排名 |
| **entity_typing** | 实体类型标注是否正确 | KGGen/GraphRAG 的 `types` 为空，**低分应读作能力缺失而非标注错误** |
| **definition_grounding** | 实体定义是否有证据支撑、不夹带常识补全 | 同上，KGGen/GraphRAG 的 definition 恒为占位符 |
| **alias_identity** | 别名是否指向同一实体 | 只有 LKG 输出别名层，其余三列没有可评对象 |
| **identity_split** | 同名不同义的实体是否被正确拆开 | `exact` 为 0% 是取舍的直接后果：它不做任何身份消解 |
| **证据覆盖** | 有多少实体/断言挂得上来源段落 | 只有 GraphRAG 不满（94.8% / 85.1%），其余三列 100% |
| **孤立实体率 / 最大连通分量** | 图的连通性 | LKG 连通性最差（32.7% 孤立），是它丢弃不确定边换精度的代价 |
| **表面名重复组** | 规范名字面重复的实体组数 | 直接反映有无身份消解层。LKG 为 0，`exact` 有 543 组 |
| **抽取耗时 / token** | 建图成本 | LKG 的数据库时间跨度含失败重试与退避，不能冒充运行耗时，故记 unavailable。KGGen 两列共用同一批抽取 |

## 怎么读这张表

**三个系统落在三个工作点上，不是同一条曲线上的三个点。**

- **llm-knowledge-graph**：A、B、C 三块全部领先，且是唯一有别名、类型、定义、身份层的系统。
  代价写在 D 表：图只有 3,309 条断言，孤立实体率 32.7%，最大连通分量仅 60.1%——它把不确定的边
  丢掉了，用连通性和覆盖面换精度。三轴呈阶梯（99.5→90.4→83.5），瓶颈明确在限定层。
- **KGGen `exact`**：D 表的规模全面领先（断言是 LKG 的 10.6 倍，谓词 7.1 倍，孤立率只有 4.4%），
  A 表的质量约为 LKG 的六到七成，两者相乘后 F 表的可消费产出是 LKG 的 6 倍。C 表整列塌陷是
  能力缺失（无类型/定义/身份层），不是标注错误。适合能自建过滤与消歧层的下游。
- **KGGen `semhash`（默认配置）**：与 `exact` 同一批抽取、同一个模型，仅去重方式不同，
  A 表却全线腰斩。根因是英文嵌入语义去重在中文上失效，谓词「等待」占全书断言 50.2%。
  **中文语料不要用默认配置。**
- **GraphRAG Fast**：E 表快 927 倍且零成本，其余全部不成立——CaRB 召回 0/48，全图只有一种谓词，
  实体是代码 import 片段。它是有意义的地板线，不是质量竞争者。

**读表时的三个陷阱：**
1. C 表中 KGGen/GraphRAG 的 typing、definition、alias 列测的是「有没有这个字段」，不是「标得准不准」。
2. A 表的 projection/scope 列对只有共现边的系统虚高，必须与 grounding 和 uncertain 一起读。
3. B 表的 fact_recovery 列已作废，book_qa 列未重判、可能受同一偏差影响；A 表与 CaRB 列是本轮唯一
   经过口径修正的结果。

**样本量：** A 表 n=200/系统（±7pp），B 表 n=48 与 24，C 表 n≈19–30（±15pp）。
C 表里 7.1% 与 4.2% 这类差距在统计上区分不开，不应据此排名。
