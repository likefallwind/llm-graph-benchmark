## 修复

- AutoSchemaKG 只替换概念化阶段的调用调度，保留官方提示、输入顺序、采样随机种子和答案拆分。调用失败直接向上传递，禁止上游把异常转换为字符串 `[]`，再被当成带用量的二元组拆成 `[` 和 `]`。
- 概念答案在写缓存前和最终导出前都检查：每个逗号分隔项必须含字母或数字（包括中文），空项和纯标点不合格。已有正常响应缓存复用；格式不合格缓存保留在 rejected-response-cache 后才重试。
- 原概念 CSV 中 43,985/47,313 条是 `[`。其派生 schema、GraphML、submission、完成标记和评测目录全部移入 recovery-audit-v2，不能作为完整结果继续评分。1,105 个抽取断点、逐阶段断点和原始成功响应缓存继续使用。
- GraphRAG 原图和成功评分全部复用。仅允许修复 JSON 最后一个 reason 字符串中的未转义引号/控制字符；其他字段必须原本可解析，修复后仍通过原 v2.2 三元组与标签一致性检查。修复原文、结果和来源均留档；不改变判定标签。
- 对缺失评分先按时间寻找该输入最早可解析的历史响应，再补调用，避免重新生成已有效的判定。已完成的评分直接复用。
- 额度/凭证终止标记保留首个具体原因，不再被后续的通用停止消息覆盖。旧额度终止标记在确认 API 恢复后归档。
